# Oriel Studio – Enterprise Design Properties & AI ArchViz Platform PRD

Product Requirements Document

Enterprise SaaS

AI + ArchViz

Product: Oriel Studio\
Module: AI Design Properties & Interactive Image Editing\
Version: 1.0\
Platform: Web-based SaaS\
Frontend: React.js / Next.js / Three.js\
Design System: Luxury Ivory, Charcoal & Champagne Gold

## 1. Product vision

Build a comprehensive AI-powered architectural visualization platform where users can upload an existing photograph, floor plan, sketch, 3D render or architectural model and transform it into photorealistic architectural designs.

The platform must cover four primary design verticals:

1. Interior Design
2. Exterior Architecture
3. Amenities & Lifestyle
4. Landscape Architecture

Each vertical must have its own contextual Design Properties panel, extensive visual element library, material catalog, mood controls, human characteristics, tags and AI editing capabilities.

Core principle: Every design property must be selectable, configurable, previewable and applicable to the selected image or region without unnecessarily changing the rest of the design.

### 3.3 Property application engine

Every property selection must create a structured editing instruction.

Example:

```
{
  "vertical": "interior",
  "element": "flooring",
  "selection": {
    "material": "italian_marble",
    "finish": "polished",
    "color": "warm_white",
    "pattern": "large_slab"
  },
  "target": {
    "region": "floor_surface",
    "scope": "selected_region"
  },
  "preserve": [
    "architecture",
    "camera",
    "furniture",
    "lighting"
  ],
  "action": "apply_material"
}
```

The AI engine must translate property selections into image-editing operations while preserving unselected regions.

## 9. Interactive image editing engine

Critical functionality

### 9.1 Selection and application workflow

## Image editing workflow

1. Upload base image

   Accept JPG, PNG, WebP, HEIC and supported architectural references.
2. Analyze image

   Identify surfaces, furniture, walls, floors, objects, geometry and scene boundaries.
3. Select target element

   Click the image hotspot or choose an element from Design Properties.
4. Choose replacement

   Select material, furniture, finish, color, model or visual reference.
5. Preview changes

   Display selected region and proposed result before committing.
6. Apply to image

   Generate the edited region while protecting unaffected elements.
7. Compare and save

   Before/After, variations, undo, redo, version history and export.

### 9.2 Image interaction modes

| Mode            | Behaviour                            |
| --------------- | ------------------------------------ |
| Select          | Click objects or regions             |
| Brush           | Paint a selection mask               |
| Erase           | Remove part of a selection           |
| Polygon         | Select a custom area                 |
| Object select   | Detect and select individual objects |
| Material select | Select surfaces by material          |
| Replace         | Replace selected element             |
| Add             | Introduce new elements               |
| Remove          | Remove unwanted elements             |
| Refine          | Improve selected region              |
| Compare         | Before/After slider                  |

### 9.3 Image preservation requirements

The AI editing engine must support:

- Mask-based inpainting and outpainting.
- Region-aware image editing.
- Surface segmentation.
- Depth and perspective awareness.
- Shadow and reflection preservation.
- Material texture consistency.
- Geometry preservation.
- Image-to-image reference guidance.
- Multiple reference images.
- Non-destructive editing.

For example, changing flooring must not unexpectedly alter furniture, wall paint, windows or camera position.

### 9.4 Hotspot system

Every generated image should support contextual hotspots.

Example for an interior:

- Flooring hotspot.
- Sofa hotspot.
- Wall paint hotspot.
- Ceiling hotspot.
- Lighting hotspot.
- Window hotspot.
- Decor hotspot.

Clicking a hotspot opens the corresponding Design Properties category.

Hotspots must be draggable where appropriate, repositionable, removable and linked to an element ID or segmented region.

## 21. Important product decisions

I recommend these architectural decisions before development:

1. One unified properties engine: Do not build separate editing engines for four verticals.
2. Configuration-driven UI: Each vertical loads its own categories and controls from JSON configuration.
3. Region-aware editing: A property must target the selected surface or object, not blindly regenerate the entire image.
4. Non-destructive editing: Preserve the original and every approved version.
5. Hybrid AI + 3D: Use image AI for photorealistic redesign and actual 3D assets for editable geometry and placement.
6. Reusable asset ecosystem: Materials, furniture, plants, humans and architectural assets should be shared across projects.
7. Consistent luxury design language: Keep the champagne-gold, ivory and charcoal visual identity throughout.
